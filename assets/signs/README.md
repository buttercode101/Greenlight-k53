# SADC Road Signs Collection

## Overview
This directory contains **real SADC (Southern African Development Community) road signs** in SVG format, organized into 5 clear visual categories:

### 1. **Restrictive (Red Circle/Hexagon)**
- Color: Red with white background
- Meaning: Stop, don't, prohibition
- Examples: STOP, No Entry, No Overtaking, No Parking, Speed Limit

### 2. **Mandatory (Blue Circle/Box)**
- Color: Blue with white symbols
- Meaning: You must do this
- Examples: Turn Left, Keep Left, Minimum Speed, Bus Lane Only, Headlights On

### 3. **Warning (Yellow Triangle)**
- Color: Yellow/white triangle with black symbols
- Meaning: Caution ahead, slow down, be alert
- Examples: Children, Curve, Pedestrians, Animals, Slippery Road, Speed Bump

### 4. **Information (Green/Blue Box)**
- Color: Green or blue rectangle with symbols
- Meaning: Helpful information, directions
- Examples: Hospital, Parking, Toll Road, Direction Signs

### 5. **Signals (Red/Green)**
- Color: Red or Green
- Meaning: Pedestrian or traffic signals
- Examples: Red Man (Stop), Green Man (Walk)

## File Naming Convention
```
{sign-name}.svg
Example: stop.svg, children.svg, hospital.svg
```

## Usage in App
Signs are referenced in the SIGNS array:
```javascript
{id:'stop', svg:'assets/signs/stop.svg', name:'Stop', fam:'red', cat:'Restrictive', ...}
```
